# 검증 범위

## 실행 검증 (최종 해시 ROM, 헤드리스 snes9x libretro)
- 콜드 부팅 → 오프닝 프롤로그, 타이틀(「루드라의 비보」 자막).
- 이름 입력(네 주인공), 시나리오 선택과 캐릭터 소개.
- 시온 시나리오: 크류누 성 첫 이벤트.
- 사렌트 시나리오: 도입 자막, 거인의 탑 이벤트, 용신의 유적, 필드 전투(명령창·무기 이름·경험치·아이템 입수).
- 리자 시나리오: 마을 대사, 여관 숙박과 저장(덮어쓰기 확인 포함), 주점 대화, 필드 전투(언령 목록·효과 설명).
- 메뉴 전체: 도구, 언령, 구성, 장비(장비 변경 창), 소지품목록, 스테이터스, 모드.
- 검증용 에뮬레이터는 모두 종료했습니다.

## 정적 검증
- 공개 도구로 재빌드한 결과가 릴리즈 ROM과 바이트 단위로 같음.
- xdelta를 원본에 적용한 결과가 릴리즈 ROM과 같음. 체크섬 유효.
- 빌드 시 모든 문자열·이름·라벨이 원래 칸 안에 들어가는지 검사, 미번역 항목 0개.
- 자막 화면(사렌트 도입·예언서·하우젠·엔딩)은 한 줄 15칸 이내인지 검사.

## 미검증
- 각 시나리오 중반 이후와 듄 시나리오의 실제 플레이, 상점 화면.
- 엔딩·스태프 롤의 실제 화면.
- 다른 에뮬레이터(bsnes 등)와 실기.
