# 검증 범위

## v2.0 한글 언령 검증
- 일본판과 한글판을 각각 헤드리스 snes9x로 언령 작성 화면까지 진행한 뒤, 같은 단어를 입력 버퍼(WRAM $0E00)에 넣고 「결정」을 눌러 판정 결과 구조체(WRAM $E200, 슬롯 4)의 효과 부분을 바이트 단위로 비교했습니다.
  - 사전 1,949칸: 한글 표기가 있는 1,918칸 전부 일치. 다른 31칸은 한글로 구분할 수 없어 뺀 단어 30개(ッ, ァ, アッ 등)와 사전에 두 번 들어 있던 バニシュ 한 칸입니다.
  - 사전 단어 두 개를 이은 조합 600개, 무작위 가타카나 200개도 비교했습니다. 다른 결과는 위 30개 단어나 풀어쓰기 표기(예: ジェ=지에가 ジ+エ보다 우선)와 관련된 경우와, 사전에 없는 무작위 단어 3개뿐이었습니다.
- 이름 입력판과 언령 입력판(11열×9행, 명령 열 포함)의 표시와 커서 이동, 글자 입력, 왼쪽 끝에서 명령 열로 넘어가기를 확인했습니다.
- 입력판으로 「샤나」를 직접 입력해 목록 등록(MP 6)과 효과 설명이 원판 シャナ와 같은 것을 확인했습니다.
- 시온의 초기 언령(이그·이그나·레후)의 표시, MP, 효과 설명을 확인했습니다.

## 실행 검증 (v1.0, 헤드리스 snes9x libretro)
- 콜드 부팅 → 오프닝 프롤로그, 타이틀(「루드라의 비보」 자막).
- 이름 입력(네 주인공), 시나리오 선택과 캐릭터 소개.
- 시온 시나리오: 크류누 성 첫 이벤트.
- 사렌트 시나리오: 도입 자막, 거인의 탑 이벤트, 용신의 유적, 필드 전투(명령창·무기 이름·경험치·아이템 입수).
- 리자 시나리오: 마을 대사, 여관 숙박과 저장(덮어쓰기 확인 포함), 주점 대화, 필드 전투(언령 목록·효과 설명).
- 메뉴 전체: 도구, 언령, 구성, 장비(장비 변경 창), 소지품목록, 스테이터스, 모드.
- 검증용 에뮬레이터는 모두 종료했습니다.

## 정적 검증
- 공개 도구로 재빌드한 결과가 릴리즈 ROM과 바이트 단위로 같음.
- xdelta를 원본에 적용한 결과가 릴리즈 ROM과 같음. 체크섬 유효.
- 빌드 시 모든 문자열·이름·라벨이 원래 칸 안에 들어가는지 검사, 미번역 항목 0개.
- 자막 화면(사렌트 도입·예언서·하우젠·엔딩)은 한 줄 15칸 이내인지 검사.

## 미검증
- v2.0 언령을 전투에서 실제로 발동한 화면, 적이 언령을 쓸 때의 이름 표시, 보물상자 힌트 대사의 실제 화면.
- 각 시나리오 중반 이후와 듄 시나리오의 실제 플레이, 상점 화면.
- 엔딩·스태프 롤의 실제 화면.
- 다른 에뮬레이터(bsnes 등)와 실기.
