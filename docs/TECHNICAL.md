# 기술 설명

## ROM 구성
- 4MB HiROM(헤더 없음). 크기는 그대로 두고 빈 영역과 원본 문자열 자리를 다시 씁니다. 체크섬(0xFFDC~0xFFDF)을 재계산합니다.

## 문자 코드와 글꼴
- 텍스트는 00~17이 제어 코드, 01~03 다음 1바이트가 2바이트 글자, 18~FF가 1바이트 글자입니다.
- 대사 글꼴: 0x1E7F80, 글자당 24바이트(16×12, 하이레스). 갈무리11 Bold 12px를 원래 크기로 그립니다(`kfont.py`).
- 메뉴 글꼴: 0x1E73C0 + (코드-0x20)×16. 갈무리7을 가로 2배(하이레스 512폭에서 화면상 원래 크기)로 그립니다.
- 가타카나 코드 0x7A~0xCB는 언령 사전(0x1CC000~, 2,048단어)이 사용하므로 코드를 유지하고 글리프만 한글 음역으로 다시 그렸습니다(ア→아, ン→ㄴ, ッ→ㅅ 등). 나머지 1바이트 빈칸 124개에 메뉴용 음절, 2바이트 코드 0x100~0x3FF에 나머지 음절(696자)을 배정합니다.
- 공백 5칸 연속은 사전 단어 t1:43으로 압축합니다.

## 문자열
- 시스템 문자열(0x308000~): 원래 자리에 들어가면 그 자리에, 넘치면 F0:0001 이후로 옮기고 포인터 표 6개와 24비트 참조(`data/sysref.json`)만 고칩니다. 즉시값 피연산자 참조는 고치지 않으므로 그런 문자열은 원래 길이 안에 맞췄습니다.
- 대사(0x30A1A0~): 은행별 영역에 다시 채우고 `data/refs.json`의 참조 중 명령 바이트(D3/D4/13/D5/D6)가 맞는 곳만 고칩니다.
- 이름 사전: 아이템(0x30000, 8바이트), 몬스터(0x30800, 8), 큰 이름 표(t0 0x31008·t1 0x31608, 12) 등 표 9개를 같은 칸 크기로 덮어씁니다.

## 그림 글자
- 메뉴 라벨: 타일맵 워드 `속성|(0x200+코드×2)`(0x8FE2~0x98BC). 길이는 `data/labels.tsv`.
- 프롤로그: 목록 0x37F711, 글자 16×16(위 0x37D711·아래 0x37D791).
- 속성 아이콘: 0x1EEF80 2bpp 16×16. 시나리오 선택의 「여행/일」: OBJ 타일 DE:EE00.

## 타이틀 자막
- 타이틀은 Mode 7 로고(BG1)이고 저작권·TM은 OAM 섀도(WRAM $0400)에 C9:0811~08BF 코드가 직접 씁니다.
- C9:08BF의 상위 OAM 표 초기화(9바이트)를 `JSL C9:F000`으로 바꿔, 새 루틴이 엔트리 15번부터 8×8 스프라이트 20개를 추가하고 상위 표($0602~)를 맞춘 뒤, C9:F200의 4bpp 타일(갈무리11 Bold)을 DMA 채널 7로 VRAM 워드 0x6100(OBJ 타일 0x10~)에 전송합니다. 팔레트는 저작권 표기와 같은 팔레트 5, 색 2(흰색)입니다(`title_sub.py`).

## 검증 도구
- `tools/emu.py`: snes9x libretro 코어를 ctypes로 불러 화면 없이 실행·입력·캡처·세이브 스테이트를 다룹니다.
- `d65.py`(65816 역어셈블), `cpu.py`·`tr.py`(세이브 스테이트에서 65816 실행 추적), `a65.py`(어셈블).
